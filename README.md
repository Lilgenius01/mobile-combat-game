# Neon Strike

A small, touch-friendly Flutter combat game with an original neon arena drawn entirely in Flutter (no image assets required).

## Play

- **Rush**: quick attack for 16 damage.
- **Heavy**: slower, stronger attack for 27 damage, with a chance to land a critical hit.
- **Repair**: restore up to 20 HP. Kane gets a counterattack after each move.
- Defeat Kane, or tap **Fight Again** to start a rematch.

## Run locally

Install Flutter, then run:

```sh
flutter pub get
flutter run
```

The app targets Flutter 3 / Dart 3 and uses only Flutter SDK widgets and canvas painting.
